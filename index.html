Data Overview

Backup Data

Download a complete JSON copy of all your data as a personal backup file.

Restore Data

Restore from a previous JSON backup. Overwrites all current app data.

Export to Calendar (.ics)

One file with every dated task as an event. Import into Google Calendar, Outlook, Apple Calendar — works anywhere.

Export to Excel (.xlsx)

Full data dump — Goals, Projects, Tasks, Comments. All fields included: assignee, progress, deadline with time, tags, hours.

Google Calendar Sync (OAuth)

Real two-way push to your Google Calendar. Requires a free Google Cloud OAuth client. Setup (one-time): 1) console.cloud.google.com → Credentials · 2) Create OAuth client (Web app) · 3) Add this page's origin (e.g. http://localhost or your domain) to authorized JavaScript origins · 4) Paste the Client ID below.
